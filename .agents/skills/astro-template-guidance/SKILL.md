# Template Guidance

Use this skill as the routing page for repository-specific architecture. Read the smallest relevant reference before changing code.

## Routing Guide

- New page, route, or section: `references/adding-new-pages.md`
- UI component or island: `references/component-usage.md`
- Markdown, MDX, frontmatter, drafts, or scheduled content: `references/content-management.md`
- Site, navigation, social, SEO, Sentry, or LLM configuration: `references/page-configuration.md`
- High-level structure and data flow: `references/project-architecture.md`
- Yarn commands or generator scripts: `references/script-usage.md`
- Tailwind, theme values, fonts, or dark mode: `references/styling-and-theming.md`
- Astroplate comparison or upstream port: `references/upstream-porting.md`

Always verify the referenced files still match the codebase. `ASTROPLATE.md` is authoritative for protected local behavior and upstream provenance.
